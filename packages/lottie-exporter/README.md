# Haiku Lottie Exporter (`packages/lottie-exporter`)

## Module Purpose

This module is responsible for converting Haiku animation projects, defined by the structures in `core-logic`, into the Lottie JSON format. Lottie is a widely used format for web and mobile animations.

## Key Responsibilities

-   **Data Transformation**: The `exportToLottie` function is the primary entry point. It takes a `HaikuProjectManager` instance.
-   **Structure Mapping**: It maps Haiku elements (rectangles, ellipses for MVP) to Lottie shape layers and shape items.
-   **Property Conversion**: Converts Haiku element properties (position, size, color, opacity) into their Lottie equivalents. For the MVP, this includes:
    -   Static properties (based on initial values or values at t=0).
    -   Animated properties for `x`, `y`, and `opacity`, converting Haiku keyframes to Lottie keyframe structures (using "hold" keyframes for MVP).
-   **Timeline Conversion**: Adapts Haiku's millisecond-based timelines and property values to Lottie's frame-based system and value ranges (e.g., opacity 0-1 to 0-100).
-   **JSON Generation**: Outputs a JavaScript object conforming to the Lottie JSON schema (a simplified version for MVP).

## Type Definitions (`types.ts`)
This module also includes `types.ts` which defines basic TypeScript interfaces for the Lottie JSON structure, aiding in the creation of a valid Lottie file. These types cover layers, shapes, transforms, and animated properties.

## Interactions with Other Modules

-   **`core-logic`**:
    -   Consumes `HaikuProjectManager`, `HaikuElement`, and `Keyframe` types as input.
    -   Uses `calculateAnimatedProperties` to get the state of elements at t=0 for static property export or as a base for animations.
    -   Directly processes `project.timelines` to convert animation data.
-   **`ui-editor`**:
    -   Calls the `exportToLottie` function to get the Lottie JSON data when the user initiates an export.
-   **`project-io`**:
    -   The Lottie JSON object generated by this module is passed to `project-io` for saving to a file.
