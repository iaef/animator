# Haiku Project I/O (`packages/project-io`)

## Module Purpose

This module handles file system interactions for the Haiku NextGen Animator, primarily focusing on saving exported animation files. For the MVP, its main responsibility is to facilitate saving Lottie JSON files generated by the `lottie-exporter`.

## Key Responsibilities

-   **File Saving**: The `saveLottieFile` function provides the mechanism to save Lottie JSON data to a user-specified file.
-   **Electron IPC**: It interacts with the Electron main process through the `window.electronAPI` (exposed by `electron/preload.ts`). When `saveLottieFile` is called, it sends an IPC message (`save-lottie`) to the main process, along with the Lottie data. The main process then handles the native "Save File" dialog and writes the file to disk.

## Type Definitions
This module includes a `global.d.ts` or similar type declaration to define the `window.electronAPI` structure, ensuring type safety when interacting with the Electron preload script's exposed API.

## Interactions with Other Modules

-   **`lottie-exporter`**: Consumes the `LottieJSON` object generated by the `lottie-exporter`.
-   **`ui-editor`**: Calls `saveLottieFile` when the user initiates a Lottie export, passing the Lottie JSON data obtained from the `lottie-exporter`.
-   **Electron Environment (`electron/main.ts` and `electron/preload.ts`)**:
    -   Relies on the API exposed by `electron/preload.ts` (`window.electronAPI.send`).
    -   The actual file saving logic (displaying dialog, writing to disk) is performed in `electron/main.ts` in response to the IPC message.
